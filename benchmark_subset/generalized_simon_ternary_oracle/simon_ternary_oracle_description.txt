The mathematical promise is based on an abstract ternary function $f: \{0,1,2\}^n \longmapsto \{0,1,2\}^n$. All additions of ternary strings are componentwise modulo $3$. The secret string $s$ is guaranteed to be nonzero. For any input $x$, define its equivalence class as $C(x) = \{x, x+s mod 3, x+2s \text{mod}\ 3\}$. The promise is that, for any two inputs $x$ and $y$, $f(x) = f(y)$ if and only if $y = x + k s \text{mod}\ 3$ for some $k$ in $\{0,1,2\}$. Thus the input space is partitioned into equivalence classes generated by repeated addition of $s$ modulo $3$. In this problem, the circuit is not required to implement the full ternary oracle for $f$. Instead, it implements a compressed binary label oracle. The implemented function is $L: \{0,1,2\}^n \longmapsto \{0,1\}^m$, where $m = \lceil \log2(3^n / 3)\rceil$. The value $L(x)$, also called $label(x)$, is an $m$-bit binary label identifying the equivalence class $C(x)$. This compressed label is sufficient for the promise because all elements in the same equivalence class have the same label, and different equivalence classes have different labels. The required oracle is $O_L \ket{x}\ket{y} = \ket{x}\ket{y \oplus L(x)}$, where \ket{x} represents the input trits, \ket{y} represents the $m$-qubit output register, and $\oplus$ denotes bitwise XOR on the output register. The oracle must preserve the input register and XOR the label into the output register. It must not overwrite the output register. Labels are assigned as follows. Ternary string indices are ordered from left to right: $x = x_0 x_1 ... x_{n-1}$. Let $j$ be the least index such that $s_j \neq 0$. For each input $x$, choose the unique $k$ in $\{0,1,2\}$ such that $x_j + k s_j \equiv 0 \text{mod}\ 3$. The canonical representative of the equivalence class containing $x$ is $c(x) = x + k s \text{mod}\ 3$. Equivalence classes are ordered lexicographically by their canonical representatives, using the symbol order $0 < 1 < 2$. The label $L(x)$ is the $m$-bit binary encoding, padded with leading zeros if necessary, of the zero-based index of the equivalence class containing $x$. Each ternary digit is encoded using two qubits. For an input string $x = x_0 x_1 ... x_{n-1}$, qubits q[2i] and q[2i+1] encode the trit x_{n-1-i}. Thus q[0] and q[1] encode the rightmost trit, q[2] and q[3] encode the next trit to the left, and so on. For the pair q[2i], q[2i+1], the displayed two-qubit ket is written as \ket{q[2i+1] q[2i]}. The trit encoding is: $0 \longmapsto \ket{00}, meaning q[2i] = 0 and q[2i+1] = 0$; $1 \longmapsto \ket{01}, meaning q[2i] = 1 and q[2i+1] = 0$; $2 \longmapsto \ket{10}, meaning q[2i] = 0 and q[2i+1] = 1$. The invalid encoding $\ket{11}$ will not appear in valid inputs. The oracle's behavior on invalid input encodings is unrestricted, but the circuit must still be a valid unitary circuit. The output qubits are q[2n] through q[2n+m-1]. If the label $L(x)$ is written as $b_0 b_1 ... b_{m-1}$, where $b_0$ is the most significant bit, then $b_r$ is stored in output qubit q[2n+r]. Equivalently, the label bits are stored in increasing output-qubit index order. For this task, $n = 2$ and the secret string is $s = 02$. Therefore $m = \lceil \log2(3^2 / 3)\rceil = \lceil \log2 3\rceil = 2$. The oracle uses $6$ logical qubits: q[0], q[1], q[2], q[3] are input qubits; q[4], q[5] are output qubits. For $n = 2$, an input string is written as $x = x_0 x_1$. The qubit layout is: q[0], q[1] encode $x_1$, the rightmost trit; q[2], q[3] encode $x_0$, the leftmost trit; q[4] stores the most significant label bit; q[5] stores the least significant label bit. For $n = 2$ and $s = 02$, the equivalence classes and labels are: $\{00, 02, 01\} \longmapsto 00$, $\{10, 12, 11\} \longmapsto 01$, $\{20, 22, 21\} \longmapsto 10$. The labels above are written in output-qubit index order q[4]q[5]. Thus the required action on valid inputs with the output register initially \ket{00} is: inputs 00, 02, and 01 should produce q[4]q[5] = 00; inputs 10, 12, and 11 should produce q[4]q[5] = 01; inputs 20, 22, and 21 should produce q[4]q[5] = 10.
